# Floating-and-submerged-tunnel

The code used for our project is provided here.

Place all files in a single folder and run them in Visual Studio Code.

- nb02_j_morison.ipynb was used to determine the hydrodynamic forces acting on the tunnel.
- back_up_29_5_rayleigh_damping.ipynb was used for the FEM analysis.
- kans_tunnel_fast_scenarios.ipynb was used for the probabilistic design assessment and for running the Monte Carlo simulations.
- nb01_a_extract_data.ipynb was used for data collection.
- nb01_d_extreme_value_analysis_JAKARTA.ipynb is used for eva.
- Mooring_attempt2_basedonslindes.ipynb last version of calculating the stiffness of the mooring lines.
